# AutoCare Pro 🚘

Modern bilingual (English / සිංහල) vehicle service and garage management **demo** for cars, motorcycles, three-wheelers and heavy vehicles.

## Features
- Dashboard with garage overview, active jobs, revenue, low-stock alerts
- Register customers and vehicles, service history
- Create/edit job cards, assign mechanics, track status, labour and parts
- Appointment scheduling
- Spare-parts inventory with SKU, prices and reorder threshold
- Branded invoices with print / Save as PDF
- Responsive POS-style interface, English/Sinhala navigation and labels
- Browser-local data, import/export JSON backups

## Run
Open `index.html` in a modern web browser. For hosting import the folder as a static site in Vercel. No build step is required.

## IMPORTANT: Demo safety
Data is stored **only in this browser** via `localStorage`. There are sample customers, vehicles, parts and jobs. No authentication, cloud storage, real-payment handling, server-side invoicing or cross-device synchronization has been implemented. **Do not use with real sensitive customer records or rely on this for production financial reporting.** Real usage requires secure authentication, managed database, audit trail, server validation, backups and privacy controls.

The Sinhala localization covers navigation and key workflows; some detailed field labels remain English.
